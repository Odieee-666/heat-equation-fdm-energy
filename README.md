# 一维热方程差分格式：第五章数值实验

本目录提供一个本科毕业论文《一维热方程差分格式的稳定性与离散能量衰减研究》第五章的可运行实验程序和一次运行的结果数据。研究对象是常系数、无源项的一维热方程，采用齐次 Dirichlet 边界条件；程序比较前向 Euler（E）、后向 Euler（B）和 Crank–Nicolson（CN）三种时间格式，空间上均使用中心差分。

## 文件

- `第五章实验程序.py`：完整网格推进、误差与能量计算、模态公式核验、计时实验；运行后将 JSON 输出到标准输出。
- `第五章实验结果.json`：论文第五章对应的一次运行结果，包含表 5.6 的七次原始计时样本及运行环境信息。

## 运行

需要 Python 3.10 或更新版本；只使用 Python 标准库，无须安装第三方包。在本目录执行：

```bash
python "第五章实验程序.py" > "第五章实验结果.json"
```

如需保留仓库中的原始结果，请将输出重定向到另一个文件名。程序输出实验数据，不直接生成论文中的图形或 PDF；论文使用这些数据在 LaTeX 中排版表格和曲线。

## 实验范围

程序检验时间收敛阶、耦合网格加密的误差、离散能量衰减、最高频模态的显式失稳，以及低频与高频叠加初值下三种格式的表现。另在相同网格和误差目标下比较所需步数与运行时间。除多模态实验使用终止时刻 `T=0.2` 外，默认 `L=κ=1`、`T=0.1`；具体网格与步数由程序给定。

数值推进使用完整网格值；独立的离散正弦模态公式用于核验关键结果。表 5.6 的计时对每个配置先预热一次，再用 `time.perf_counter()` 测量七次，保存中位数、最小值、最大值和逐次样本。运行时间受 CPU、Python 版本和系统负载影响，不能当作三种格式的一般速度排名。本文的稳定性和误差结论仅针对所述模型、边界条件与实验设置。
