# 一维热方程差分格式：第五章数值实验

本目录提供本科毕业论文《一维热方程差分格式的稳定性与离散能量衰减研究》第五章的可运行实验程序和一次运行的结果数据。研究对象是常系数、无源项的一维热方程，采用齐次 Dirichlet 边界条件；程序比较前向 Euler（E）、后向 Euler（B）和 Crank–Nicolson（CN）三种时间格式，空间上均使用中心差分。

## 文件

- `第五章实验程序.py`：完整网格推进、误差与能量计算、模态公式核验、计时实验；运行后将 JSON 输出到标准输出。
- `第五章实验结果.json`：论文第五章对应的一次运行结果，包含表 5.8 的七次原始计时样本及运行环境信息。

## 运行

需要 Python 3.10 或更新版本；只使用 Python 标准库，无须安装第三方包。在本目录执行：

```bash
python "第五章实验程序.py" > "第五章实验结果.json"
```

如需保留仓库中的原始结果，请将输出重定向到另一个文件名。程序输出实验数据，不直接生成论文中的图形或 PDF；论文使用这些数据在 LaTeX 中排版表格和曲线。

## 实验范围

程序检验时间收敛阶、耦合网格加密的误差、离散能量衰减、最高频模态的显式失稳，以及低频与高频叠加初值下三种格式的表现。另在相同网格和误差目标下比较所需步数与运行时间。默认 `L=κ=1`、`T=0.1`；原六组多模态末态实验使用 `T=0.2`，新增负值包络验证使用 `T=0.45`。具体网格与步数由程序给定。

数值推进使用完整网格值；独立的离散正弦模态公式用于核验关键结果。表 5.8 的计时对每个配置先预热一次，再用 `time.perf_counter()` 测量七次，保存中位数、最小值、最大值和逐次样本。运行时间受 CPU、Python 版本和系统负载影响，不能当作三种格式的一般速度排名。本文的稳定性和误差结论仅针对所述模型、边界条件与实验设置。

## 两模态初值的首次负值验证

`multimode_experiment(a=0.5)` 支持高频初始振幅 `a`，默认参数保留原有 `T=0.2, M=800/8` 六组多模态实验。`complete_negative_classification(n, r, a)` 对本论文的最低频与最高频两模态初值族返回所属区间与首次严格负值时层：`0<r<=r_star` 返回 `None`，`r_star<r<r_double_star` 使用 `predict_first_negative_step(a, rho)`，`r>=r_double_star` 返回 `1`，其中 `r_star=1/sin(pi/n)`、`r_double_star=1/(2 sin(pi/(2n))²)`。预测函数以输入浮点数的精确有理数表示核验整数临界，严格区分等于零与小于零。`gH>=0` 时也属于第一段；此时高频项的节点符号与时层奇偶无关。

`multimode.first_negative_validation` 字段保存 `N=40, r=40` 下 `a=0.25, 0.50, 0.75` 的验证。各组实际推进全部 39 个内部节点 8 步（零边界始终固定），从初始层起搜索最小值小于 `-1e-12` 的首个时层，断言理论与观测步数均为 `7, 4, 2`。每组还独立延长到 18 步，在 `cases` 中记录延长实验的最深时层和最深负值，供论文表 5.6 核对。原 8 步逐层最小值、负节点编号、因子与幅值比及中心值字段保留。

`negative_envelope` 子字段给出 `a=0.5, T=0.45, M=18`、保持 `dt=0.025, r=40` 的独立包络核验：`n_star≈13.398265865`，`phi_13≈0.3212159045`，`phi_14≈0.3210378960`。包络的整数峰值是第 13 步；该层同奇偶节点的最大正弦因子为 `cos(pi/40)`，所以完整网格最深负值在第 14 步、`i=20`，为 `-0.321037896`。第 13 步最小值在 `i=19`，为 `-0.320225703`；第 8 步为 `-0.271578753`，最深值约深 `18%`。`min_by_step` 和 `argmin_by_step` 保存第 0–18 步的逐层结果。程序断言观测峰值幅度与 `Phi(peak_step_theory) ×` 相应奇偶节点最大正弦因子的差小于 `1e-10`。

`third_interval_checks` 对 `r=r_double_star≈324.3945, 400, 1000` 分别实际推进完整网格一步，断言全部奇数内部节点为负，三次最小值均在 `i=19`。程序还断言中间段各负节点与时层同奇偶、所有节点与两模态精确表达式一致，并检查预测函数的整数临界值及其相邻浮点值。分类只适用于上述初值族，不能作为任意非负初值的 CN 全局保正条件。
